# 📁 Automated File Organizer & Batch Renamer

An automated python tool for cleaning up cluttered directories by sorting files into categorized subfolders and batch renaming with regex patterns.

## 🚀 Features

- 📂 **Auto-Categorization**: Automatically sorts files into `Images`, `Documents`, `Audio`, `Video`, `Code`, and `Archives` based on file extensions.
- 🧪 **Dry-Run Mode**: Preview file movements or renames before executing disk changes.
- 🏷️ **Regex Batch Renaming**: Rename multiple files matching regex patterns with captured groups.
- 💻 **CLI & API**: Usable both as an interactive command-line application or as a reusable Python module.

## 💻 Usage

Run doctests:
```bash
python file_organizer/file_organizer.py
```

Launch CLI mode:
```bash
python file_organizer/file_organizer.py --cli
```
