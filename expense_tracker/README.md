# 📊 CLI Expense Tracker

A lightweight command-line tool written in Python to track personal expenses, categorize spending, calculate totals, and save history in local JSON files.

## 🌟 Features

- 💸 **Record Expenses**: Track amount, category, date, and descriptions.
- 🏷️ **Category Summaries**: View instant total spending grouped by category (Food, Travel, Utilities, etc.).
- 📅 **Date Range & Filters**: Filter history by specific categories.
- 💾 **JSON Persistence**: Expenses are automatically stored in `expenses.json`.

## 🚀 Usage

Run doctests:
```bash
python -m doctest expense_tracker.py -v
```

Launch interactive CLI:
```bash
python expense_tracker.py --cli
```
